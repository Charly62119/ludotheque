# Ludothèque

App mobile (PWA) pour gérer sa collection de jeux de société, ses parties et ses stats.
Les données restent sur le téléphone (bouton ⬇ en haut à droite pour exporter / importer une sauvegarde).

Mise en ligne : Settings → Pages → Deploy from a branch → main / (root).
Après une modification, augmenter `CACHE` dans `sw.js` (ludotheque-v2, v3…).
